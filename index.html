📝 Catatan Harian

Tulis kegiatan Anda pada tanggal tertentu (cth: bantu bongkar kontainer, stock opname). Catatan otomatis muncul di kolom Keterangan pada laporan produktivitas.

⚠️ Tabel keterangan_harian belum ada di Supabase, jadi catatan sementara hanya tersimpan di browser ini. Jalankan SQL ini sekali di Supabase → SQL Editor, lalu muat ulang: 
create table if not exists keterangan_harian (
  id bigint generated always as identity primary key,
  tgl date not null,
  nama text not null,
  keterangan text not null,
  updated_at timestamptz default now(),
  unique (tgl, nama)
);
alter table keterangan_harian enable row level security;
drop policy if exists "kh_all" on keterangan_harian;
create policy "kh_all" on keterangan_harian for all using (true) with check (true);

create table if not exists receiver_pallet (

  tgl date not null,

Kelola User

Crew memilih nama dari roster Picker/Packer/Receiver (sekali saja, perangkat mengingat). Bagian mengikuti roster. Di sini admin bisa menonaktifkan atau menghapus akun.

⚠️ Tabel app_users belum siap di Supabase (atau belum punya kolom bagian), jadi akun sementara hanya tersimpan di browser ini. Jalankan SQL ini sekali di Supabase → SQL Editor, lalu muat ulang halaman: 
create table if not exists app_users (
  id bigint generated always as identity primary key,
  username text unique not null,
  nama text not null,
  role text not null default 'CREW',
  bagian text,
  pass_hash text default '',
  aktif boolean default true,
  last_login timestamptz,
  created_at timestamptz default now()
);
-- jika tabel sudah terlanjur dibuat sebelumnya:
alter table app_users add column if not exists bagian text;
alter table app_users alter column pass_hash drop not null;
alter table app_users alter column pass_hash set default '';
alter table app_users alter column role set default 'CREW';
alter table app_users enable row level security;
drop policy if exists "au_all" on app_users;
create policy "au_all" on app_users for all using (true) with check (true);
